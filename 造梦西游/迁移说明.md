## 新设备开始

```sh
git clone --branch zmxol-v6.2-handoff --single-branch ssh://git@ssh.github.com:443/a3035542378-bit/home.git
cd home/造梦西游
python3.12 -m venv .venv
.venv/bin/python -m pip install pytest cryptography
.venv/bin/python -m pytest tools/zmxol/test_search_forum.py tools/zmxol/test_offline_shop.py -q
```

需要另行安装Node.js运行JS契约测试。完整工具测试还依赖Java/OpenJDK和JADX 1.5.5中的apksig/dexlib2，配置与构建命令见`tools/zmxol/README.md`。原Mac绝对路径不可直接复用；Android SDK、模拟器和Python虚拟环境均应在新设备安装。

先读`docs/zmxol-codex-checkpoint.md`、`docs/zmxol-offline-v62-report.md`。当前可分发基线仍V6.1 R3，V6.2只完成路由依据和纳戒入口调查，不能声称特殊商城闭环完成。
