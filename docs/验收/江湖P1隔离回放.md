# 江湖 P1 隔离回放

R1 使用合成微信事件、临时 SQLite 数据库和生产本地消息路由。书生先升至 Lv.3，空手且开战饥饿至少 20。以下正文取自监听器回放写入的发件箱。

## 蒙面人首战

```text
⚔️ 迎战蒙面人
第1回合　你出招 9，蒙面人出招 25
第2回合　你出招 9，蒙面人出招 25
第3回合　你出招 9，蒙面人出招 25
你没能击退蒙面人。再来客栈，找引路人解围。
二狗历练
```

## 重启后逐字发送败北回执末行

```text
蒙面人拦住去路。亮出信物，请引路人了结追索。
二狗了结追索
```

## 发送解围选项并重放同一消息

```text
🏮 第一章·客栈风云 已完成
引路人出手制敌，你与这段恩怨就此了结。
【切磋 @群友】邀一位朋友试试身手
```

R1 最终首胜入账一次、章节完结一次，入门恭贺零条。武夫正向用例从 100 饥饿开始，固定无奇遇。连续领 4 小时获得 16 常规潜能，饥饿降至 0。分四次领取同样获得 16 常规潜能，中途两次吃包子共花 10 两，最终饥饿 20。

## 消息路由兼容性

共享目录按同一个江湖开关显示或隐藏【江湖录帮助】，江湖帮助、江湖菜单、江湖录菜单指向同一主题。隔离监听器回放开启本群智能对话，并配置包含主线、历练、打坐、确认加点的关键词。裸发历练没有回执，真实 @ 的历练新增一条模型请求。文字前缀完成 R1 时模型队列增量为零。含额外文字的「二狗聊聊主线」命中群关键词，单发「二狗主线」进入镖信剧情。败北正文来自战斗结算，数据库记录该群该玩家已败北。

## 原型取值与签字范围

福缘每有效小时以福缘值百分比抽取，单次领取最多拾得 1 两。NPC 身法依次为假镖师 12、野狗 15、蒙面人 18。三回合未分出击倒时比较剩余气血比例。切磋独立计算模拟气血，参与者无损。入门恭贺与章节完结各有独立业务键，合并在同一条群内回执发送。上述选择供隔离盲测复核。

命令覆盖与精确断言见 `二狗机器人/tests/test_jianghu.py`。两名真人只看回执的盲测待完成，当前仅在隔离测试库开关玩法。
