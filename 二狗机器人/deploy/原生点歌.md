# Linux 微信点歌

在已绑定且允许点名回复的群发送「二狗点歌 许嵩 有何不可」。歌曲名称可单独使用，指定歌手可减少同名曲目的歧义。使用本群配置的指令前缀，智能模式下的真实 @ 继续走本群模型。

## 运行条件

- 微信组件基于 agent-wechat v2.7.1。在上游源码根应用仓库中 `docs/验收/原生音乐卡/agent-wechat-2.7.1-music.patch`，按上游构建方法生成 release 版 wx。用同目录的 `test_isolated_music.py` 验证 HTTP 入口。
- 在现有微信服务的 ExecStart 中仅替换可执行文件，保留服务用户、数据目录和监听参数。发送服务 `ergou-replies` 设置 `Environment=ERGOU_QQ_MUSIC=1`。原版组件和既有账号数据可继续用于回滚。
- 查询使用 QQ 音乐的匿名搜索、官方歌曲分享页和播放接口。优先用平台实际返回的整曲地址，其次用官方试听地址。查询和签发在投递前进行，应用数据库沿用原有点歌任务，不保存临时音源。
- 命中曲目但没有可用音源时发送 QQ 音乐歌曲页。搜不到或搜索服务不可用时发送既有搜索入口。发卡通过原发送任务的幂等键核对回执，结果不确定时不补发。
- 回滚时恢复上一发布目录和 wx 启动配置，移除本次发送服务环境变量，执行 systemctl daemon-reload 并重启相关服务。核对实际运行的 wx 路径、账号在线状态、群绑定和服务健康。
