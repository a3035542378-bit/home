# 微信群指令与智能模式

群文字按当前群的开关处理。模型来自本群后台验证过的供应商、模型 ID 与凭据。微信原生提及由消息元数据核验。

| 状态 | 微信原生 @二狗 | 二狗前缀，无原生提及 |
|---|---|---|
| 智能模式开启 | 交给本群配置的大模型，包括积分、菜单、钓鱼等字样 | 走本地指令 |
| 智能模式关闭 | 走本地指令 | 走本地指令 |

管理员的「开启智能对话」「关闭智能对话」优先本地鉴权。普通未点名聊天沿用既有忽略规则。已绑定群的主人可用「二狗绑定状态」「二狗停用本群」，新群首次激活仍用微信的 @二狗。

## 路由与兜底

在开关指令完成鉴权后分流：

```python
if mentioned and models.api_first(db, e["grp"]):
    return models.submit(db, e, cmd or "群成员点名了你，请简短回应。")
```

所有本地指令、游戏、群关键词依次匹配后，再检查已有的本地笑话、故事等话题；均未命中时使用统一兜底：

```python
UNKNOWN_COMMAND = "🤖 没找到这个指令哦。发送「{prefix}菜单」查看功能，或发「{prefix}钓鱼玩法」看钓鱼指南。"
return respond(db, e, cmd.strip(), fallback=UNKNOWN_COMMAND.format(prefix=prefix))
```

## 微信事件回放验收

1. 「二狗切换钓场」列出所有已配置钓场和切换示例，成员的位置保持原值。
2. 「二狗钓鱼菜单」与「二狗怎么钓鱼」返回相同的钓鱼面板。
3. 「二狗瞎写的乱码」立即返回本地兜底，模型队列无新增。真实 @ 的相同提问在开启时进入本群模型，关闭时返回本地兜底。

可运行用例见 `tests/test_mobile_router.py`。
