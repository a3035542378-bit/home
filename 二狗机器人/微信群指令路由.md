# 微信群指令与智能模式

群文字按当前群的开关处理。模型来自本群后台验证过的供应商、模型 ID 与凭据。微信原生提及由消息元数据核验。

| 状态 | 微信原生 @二狗 | 二狗前缀，无原生提及 |
|---|---|---|
| 智能模式开启 | 交给本群配置的大模型，包括积分、菜单、钓鱼等字样 | 走本地指令 |
| 智能模式关闭 | 走本地指令 | 走本地指令 |

管理员的「开启智能对话」「关闭智能对话」优先本地鉴权。未点名的普通群文字在微信适配器入口丢弃，只推进事件游标。偷鱼请发「二狗偷鱼」并在微信选择一位群友；只 @ 群友不会触发。已绑定群的主人可用「二狗绑定状态」「二狗停用本群」，新群首次激活仍用微信的 @二狗。

## 路由与兜底

在开关指令完成鉴权后分流：

```python
if mentioned and models.api_first(db, e["grp"]):
    return models.submit(db, e, cmd or "群成员点名了你，请简短回应。")
```

本地路由保留明确动作、群规则与带编号的游戏指令的优先级。「卖17号鱼」与「卖#17」用完整动作匹配；「别卖17号鱼」不会卖出库存。「卖#17？」只提示编号用法。明确请求缺参时复用玩法自己的群开关和库存校验，由钓场或鱼包模块生成帮助。

```python
    if canonical in ("钓鱼玩法","切换水域","查看鱼包") or canonical.startswith("切换水域 "):
        return fishing.play(db,e,canonical,prefix,cfg)
```

未命中精确指令时，口语导航只打开面板。以下是 intents.py 中的实际匹配逻辑。

```python
def navigation_hint(text):
    """精确指令全部未命中后，关键词组合只打开只读面板。"""
    if any(word in text for word in ("换","切","去")) and any(word in text for word in ("场","图","水域")):
        return "切换水域"
    if "钓鱼" in text and any(word in text for word in ("菜单","帮助","玩法","怎么玩")):
        return "钓鱼玩法"
    if "鱼包" in text or "背包" in text:
        return "查看鱼包"
    return None
```

engine.py 在本地路由末尾选择查询指引或通用兜底。已有离线笑话、故事和追问仍可回复。

```python
UNKNOWN_COMMAND = "🤖 没看懂这个指令。发「{prefix}菜单」查看我能做什么，或发「{prefix}钓鱼玩法」查看钓鱼指南。"
    guide = intents.navigation_hint(cmd)
    if guide:
        return fishing.play(db,e,guide,prefix,cfg)
    fallback = UNKNOWN_COMMAND.format(prefix=prefix)
    if "天气" in cmd:
        fallback = f"🤖 没看懂这个指令。想查天气，请发「{prefix}天气 北京」。发「{prefix}菜单」查看更多。"
    return respond(db,e,cmd.strip(),fallback=fallback)
```

## 微信事件回放验收

1. 「二狗切换钓场」列出所有已配置钓场和切换示例，成员的位置保持原值。
2. 「二狗钓鱼菜单」与「二狗怎么钓鱼」返回相同的钓鱼面板。
3. 「二狗瞎写的乱码」立即返回本地兜底，模型队列无新增。真实 @ 的相同提问在开启时进入本群模型，关闭时返回本地兜底。

4. 「大家晚上好」与只 @ 群友的偷鱼消息保持静默，原生监听推进游标，正文不进入入站表。
