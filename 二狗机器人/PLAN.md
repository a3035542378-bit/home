# 微信二狗机器人实施计划

依据 [微信二狗机器人详细设计需求文档 V1.1 评审稿](https://chatgpt.com/library/share/libfile_fde3_f-10d7d6cf5c2481918ba8fa0bcf38799c_c785474d68c881918f4852ed60484cd0?account_id=personal)，2026-11-18。交付范围包括 G0、G1、G2。以下顺序用于组织开发，最终准出仍按需求 5.5。

|阶段|实现步骤|退出证据|
|---|---|---|
|G0 接入|确认桌面微信和适配器版本、许可证、校验值、稳定群及成员 ID、接收确认层级。授权测试群验证收发，区分网络中断、退出、二维码过期、恢复。分别验证锁屏、RDP 断开、注销、崩溃、重启|记录真实账号测试标识、输入、预期、实际、版本、时间、trace_id。覆盖 AT17、18、22|
|G1 持久化|SQLite WAL、FULL 同步，短事务入站、账号绑定、按接收序列消费、业务/积分/发送意图原子提交；发送租约、明确失败退避及未知状态|重复上报、并发、崩溃、未知发送、恢复演练 AT01–03、19、21|
|G1 群内闭环|三类代表游戏、三局并行、报名和定向作答、截止、不可覆盖的积分流水与北京时间榜单；欢迎、群规、定时任务|AT04–08、10；用正常命令入口重放，检查状态与数据库约束|
|G1 后台|本机登录、群范围授权、版本化配置、会话/积分/任务/审计及备份恢复；明确模拟运行标识|跨群详情与导出测试 AT16，记录部署和恢复步骤|
|G2 业务|独立游戏清单逐项冻结，按猜题、文字、养成扩展，每项交付规则、素材、恢复及验收记录；规则命中、报表、查询、投票、抽签、撤回、插件和多账号切换|AT09、11–15、19、20、24；逐游戏走启动、参与、结束和错误流程|
|G2 容量与交付|200 群分散及热点、3 局并行，命令占比 5/30/100%；20 条/秒 60 分钟、50 条/秒 5 分钟及连续 72 小时，真实群另验|AT23，分阶段延迟、成功率、积压、异常明细；汇总 D01–D08、部署矩阵与未解决问题|

## 需要冻结的输入

真实适配器及维护责任、测试群；120 款玩法清单；账号数与目标硬件；天气/快递供应商、预算及出站范围；撤回内容告知、可见角色及容量；验收环境、服务时间与责任人。模拟账号和模拟群独立命名。供应商未配置时给出明确状态，内容留存默认关闭。真实微信动作需要具体测试范围。

## 开发与验收记录

已确认本次先交付可独立运行的 Windows 本地版。真实群自动化仍按稳定账号、群、成员及消息 ID 验收，保留在后续 G0 里程碑。实测仅在已获授权的群进行过一条桌面发送。

已执行的检查与剩余条目见 [验收记录](ACCEPTANCE.md)。版本矩阵按实测记录，未验证的组合不标为支持。

G0 按群消息插件路线推进。第一步核对 GitHub 上游的群事件接口和 Windows 版本矩阵，第二步用真实 Wechaty SDK 加载只收插件并验证本机入库，两步均已完成。第三步仍需能复用微信 4.2.0.13 当前登录会话且提供稳定 ID 的事件源。在授权群取得一条自然产生的消息后，核对群 ID、成员 ID、来源消息 ID，再验证重连重放与去重。[组件核对与操作步骤](ergou/wechaty/README.md)

已完成 WeFlow 公开 API 的单群增量接入和协议回归。上游已宣布无限期停更，本机没有已配置的服务。G0 实收仍需要兼容且可授权的事件源；本机端口探测、模拟数据与插件回归分别记录。

用户随后授权同一微信号另行扫码。已采用 Agent WeChat 2.7.1 独立托管会话，真实验证账号和群成员身份，完成目标群绑定、SSE 监听与持久化游标。2026-11-18 22:56:26（北京时间）已通过首条授权群真实入站文本验收，详见[验收记录](ACCEPTANCE.md)。[操作手册](ergou/wechaty/README.md#agent-wechat-独立扫码会话)

G0 已补验真实事件跨连接重放。监听器新增单实例保护及上游保留期过后的恢复与审计。真实登录失效和二维码过期场景仍待单独验证。

入群欢迎与退群提醒接入 Agent WeChat 的完整群名册刷新流程。两个群使用不同开关的隔离验收覆盖首次建档、重连、关闭、重新确认和幂等发送。真实群以运营开关、逐项授权以及随后实际发生的成员变化验收。

2026-11-18 已按群接入运营模型配置、官方接口验证、多轮聊天和点名回复投递。授权群已完成一条真实点名指令的插件收发核对。运营人员填入真实供应商密钥后，可在同一后台完成模型连通性验证并启用群聊。具体验收结果见 [验收记录](ACCEPTANCE.md)。
