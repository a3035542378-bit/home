# 二狗鱼获品级

## 给群成员的四句话

- 🎣 发「二狗抛竿」，鱼入包时定品级，小鲤鱼也有机会升到传说。
- ✨ 鱼包里带「升品」的鱼超过了它的基础品级。品级越高，同样重量卖价越高。
- 🎁 在本群刷新同种鱼的个人最高品级可领积分，首次达到传说得 500 分。
- 🌊 发「二狗巨物鱼讯」追活动巨物，活动目标有机会出神话。「二狗图鉴」看本群最近喜报。

## 鱼种和单尾品级

「二狗史诗图鉴」「二狗传说图鉴」按鱼种筛选。在有对应鱼种的水域，免费饵常规抽取时遇到史诗鱼种的概率为 0.12%，遇到传说鱼种为 0.01%。高级饵分别乘 1.5，顶级饵乘 2。上钩后仍需通过收线、装备和脱钩判定。新增 6 种史诗鱼种（80～600 公斤）、3 种传说鱼种（380 公斤～2 吨）。

体型按鱼种重量区间的位置划分，达到 30%、75%、97% 时分别进入标准、大型、巨物。鲤鱼沿用 12 公斤的巨物门槛，活动目标成功入包时按巨物档结算。

| 鱼种 | 小型 | 标准 | 大型 | 巨物 |
|---|---|---|---|---|
| 普通 | 普通 | 普通 | 优良 | 稀有 |
| 稀有 | 普通 | 优良 | 稀有 | 史诗 |
| 珍品 | 优良 | 稀有 | 史诗 | 传说 |
| 史诗 | 稀有 | 史诗 | 史诗 | 传说 |
| 传说 | 史诗 | 史诗 | 传说 | 传说 |

后两行是新增鱼种的默认矩阵。一条鱼入包时独立抽一次升品签。活动窗口内成功钓走本轮目标额外加一级；平时自然遇到巨物按常规结算。

| 升品概率 | 原级 | 加一级 | 加两级 | 加三级 | 加四级 |
|---|---:|---:|---:|---:|---:|
| 小型 | 88.88% | 10% | 1% | 0.1% | 0.02% |
| 标准 | 89.5% | 9% | 1.3% | 0.18% | 0.02% |
| 大型 | 84% | 14% | 1.7% | 0.28% | 0.02% |
| 巨物 | 97% | 2.9% | 0.1% | 0 | 0 |

小型原级权重从草案的 88.9% 调到 88.88%，每行共一万签。积分按本群、玩家、鱼种分别记最高品级。六档首次突破奖励依次为 0、5、20、100、500、1000 分，跳级只发落点那一档。售价以鱼种配置的基础价乘体重系数（下限 0.8 至上限 1.5 线性变化，超出按端点）和品级系数（1、1.2、1.5、2、3、5），最后四舍五入至整鱼币。

## 核心函数伪代码

```text
roll_upgrade(tier)
    在 0 至 9999 间均匀取一张签
    按本体型的五段签数定位，返回 0 至 4

final_grade(fish, grams)
    根据本竿命中的活动目标或实际重量确定体型
    base ← 基础矩阵[鱼种稀有度, 体型]
    final ← min(活动目标 ? 神话 : 传说, base + 活动目标加成 + roll_upgrade(体型))
    返回 final，以及 final > base 的升品标记

award_first_grade_points()
    在处理本次入站消息的同一事务中读取同群本人同种鱼的历史最高品级
    个人最大重量独立取新旧最大值
    若首次亲钓或最终品级突破纪录，保存最终品级及其升品标记
    若突破档有奖励，在本群积分账本写入该档积分
```

## 存储与兼容

下列为旧表首次升级时执行的列变更。初始化按列检测，新库直接建成目标结构。已有鱼获、展品和个人最重纪录用现存鱼种、重量确定基础品级，保留原售价；历史数据不补抽签、不追发积分。无法识别鱼种的旧鱼保留原状。

```sql
ALTER TABLE fishing_pond ADD COLUMN grade INTEGER CHECK(grade BETWEEN 0 AND 5);
ALTER TABLE fishing_pond ADD COLUMN grade_upgraded INTEGER NOT NULL DEFAULT 0;
ALTER TABLE fishing_exhibits ADD COLUMN grade INTEGER CHECK(grade BETWEEN 0 AND 5);
ALTER TABLE fishing_exhibits ADD COLUMN grade_upgraded INTEGER NOT NULL DEFAULT 0;
ALTER TABLE fishing_species ADD COLUMN best_grade INTEGER CHECK(best_grade BETWEEN 0 AND 5);
ALTER TABLE fishing_species ADD COLUMN best_grade_upgraded INTEGER NOT NULL DEFAULT 0;
CREATE TABLE IF NOT EXISTS fishing_grade_news (
  grp TEXT PRIMARY KEY REFERENCES groups(id), member TEXT NOT NULL, fish TEXT NOT NULL,
  grams INTEGER NOT NULL, grade INTEGER NOT NULL CHECK(grade IN (4,5)),
  upgraded INTEGER NOT NULL, legends INTEGER NOT NULL
);
```

鱼包、鱼塘、展品的实物在转移时保留编号、克重、售价和品级。卖鱼或换展后，亲钓纪录仍保留。每群仅保存最近一条传说或神话喜报和升品传说累计数。史诗起在抛竿回复里报喜，随机抽签确实提高最终品级时使用「欧皇」。目前 Linux 微信适配器公开的是会话置顶接口，喜报固定在本群图鉴内。

## 验收

| 固定抽签用例 | 预期最终品级 |
|---|---|
| 小型普通鲤鱼，升四级 | 传说 |
| 小型珍品金色锦鲤，升三级 | 传说 |
| 活动巨物鲤鱼，额外一级、抽升两级 | 神话 |
| 标准普通鲤鱼，升零级 | 普通 |

| 穷举全部 10,000 张签 | 命中数 | 条件概率 |
|---|---:|---:|
| 已钓获小型普通鲤鱼 → 传说 | 2 | 0.02% |
| 已钓获小型珍品鱼 → 传说 | 12 | 0.12% |
| 已钓获活动巨物鲤鱼 → 神话 | 10 | 0.10% |

各钓场的全部本地鱼种都能成为活动目标，包括史诗、传说鱼种。每轮先按基础竿和免费饵的稀有度权重抽一档，再从本场同档鱼种中等概率选一条。鱼讯会写明本轮鱼名。

普通鱼种的活动巨物（如鲤鱼、白条）其余结果为 9,700 张史诗、290 张传说。稀有鱼种的活动巨物有 3% 出神话；珍品、史诗和传说鱼种的巨物基础品级已达传说，钓获活动目标后直接升至神话。上述分母均为已成功钓获指定鱼的次数。连续多竿独立抽签，没有累计保底。配置与结算见 `ergou/fish_grades.py`，验收见 `tests/test_fish_grades.py` 和 `tests/test_giant_fish.py`。
