# 二狗主人与本群权限

## 给群主的说明

进群后可以直接参与钓鱼等玩法，群主管理权限初始为「待授权」。
主人发「二狗授权群主」，你就能管理本群设置和管理员。
用「二狗查看群主状态」看授权时间；授权成员时请用微信原生 @。
主人可以随时撤销。微信群主换人后，新群主需要重新授权。

## 数据与鉴权

建表 SQL 在 `ergou/permissions.sql`。群启停与绑定版本沿用原有的群表，通过 `group_binding_state.status` 读取实际启停状态。时间以 Unix 时间存储，以北京时间展示。老群原始绑定人无法核实的留空。每个机器人有一位主人；领养通过服务器 `python3 -m deploy.group_workers adopt 稳定微信ID` 一次生效。领养后，原绑定管理员名单退出鉴权，跨群激活由主人操作。

```text
如果是本机器人已领养的主人 → 主人 5
若群未激活或受限 → 访客 1
若是平台当前群主 → 获得有效授权为 4，待授权为 2
其余按本群成员角色 → 管理员 3、成员 2、访客 1
检查指令所需等级；主人专属指令同时核对主人身份
```

## 四条核心指令

| 指令 | 身份与处理 |
|---|---|
| 二狗授权群主 | 仅主人。核对平台当前群主，指定 @ 时必须匹配，更新本群授权并记审计。 |
| 二狗取消群主授权 | 仅主人。将当前群主恢复到待授权，重复撤销不重复写审计。 |
| 二狗查看群主状态 | 主人或本群已授权群主。显示群主、状态、授权人及授权时间。 |
| 二狗群主授权列表 | 仅主人。按机器人分页显示群名、编号和授权状态，页码接在指令后。 |

主人或已授权群主可发「二狗授权管理员 @成员」「二狗取消管理员 @成员」「二狗本群设置 游戏 关闭」；本群设置还支持投票、抽签。主人、已授权群主和管理员可重置或结束游戏局。列为访客的成员不能调用玩法。智能对话仍需微信原生 @ 和本群已验证的模型配置，开关由主人或已授权群主管理。

主人可在群内发「二狗主人转移 @成员」，或发「二狗全局配置 新群游戏 开启」设置新群默认值。转移即时生效，现有群授权保留。主人可私聊二狗查看授权列表，再在私聊或另一个已绑定群发「二狗管理群 #1 取消群主授权」。群编号取自列表。

节点核对平台群资料时发现群主换人，会撤销旧授权，向本群提示新群主待授权。资料暂不可核实时暂停依赖该身份的管理权。已确认的离群事件或完整名册可撤销已离群群主。二狗离群后再加入同群，核实群主身份后恢复原授权。微信禁言、移出成员的群内入口检查三级权限；当前节点收到这些指令仅反馈能力状态。该版本未开通平台移人权限，微信适配器亦未提供成员禁言接口。

## 验收用例

| 操作 | 预期 |
|---|---|
| 待授权群主授权管理员 | 拒绝，提示尚未获得主人授权 |
| 主人授权后，群主授权管理员 | 成功，管理员限本群生效 |
| 主人撤销后，原群主重置或结束自己发起的游戏 | 拒绝 |
| 微信群主换人，新旧群主分别查看本群设置 | 新群主待授权，旧群主无权限 |
| 普通成员授权管理员 | 拒绝，角色表无新增记录 |
| 主人连续两次撤销同一授权 | 状态为待授权，只有一次 revoke_group_owner 审计 |

测试通过模拟微信事件，经过监听、入站处理、角色校验和回复队列；另外覆盖主人转移、私聊远程管理。测试文件为 `tests/test_owner_roles.py`。
