# 微信二狗群聊机器人

本机 Python + SQLite 群聊工作台。默认进入本地模拟群，可实际运行游戏、积分、投票、抽签、规则检测、定时通知及后台管理。真实接入状态见 [验收记录](ACCEPTANCE.md)。

## 云端运营后台

仓库中的 `203.0.113.10` 为文档示例地址。首次部署时，在云端启动和密码查看脚本中填写自己的服务器地址及 SSH 密钥路径。

手机和其他电脑可直接打开 [公网 HTTPS 后台](https://203.0.113.10/ergou/)。浏览器第一次提示验证时，输入公网访问账号和独立密码。随后在二狗登录页输入运营账号和原密码。在部署用的 Windows 账号下双击 [查看公网访问密码.cmd](查看公网访问密码.cmd) 可查看当前公网访问账号和密码。访问凭据由 Windows 按用户加密保存。

在已配置免密 SSH 的这台电脑上，双击 [打开云端运营后台.cmd](打开云端运营后台.cmd)，使用部署时设置的 `admin` 和初始密码登录。入口是 [云端工作台](http://127.0.0.1:8767/)。SSH 将本机 8767 端口连接到服务器的 8766 端口。服务器使用独立的 systemd 服务 `ergou-web` 和 `ergou-wechat`。

在「后台账号」中选择角色和可管理的群，再创建运营、群管或只读账号。「微信扫码登录」用来登录机器人使用的微信号。点击「获取登录二维码」并在手机上确认，页面会显示当前连接状态。二维码过期时可重新获取。只有系统管理员可以使用这两个页面。

迁移工具 `python -m deploy.export_data <源数据库> <全新数据库>` 导出群配置、游戏和积分历史，以及停用的定时模板。新服务器需在「大模型配置」和「语音唤醒」重新验证供应商凭据。Linux 使用服务用户私有的 `/var/lib/ergou/credentials/credential.key` 加密凭据。需要灾备时，与数据库分开安全保管该文件。

**已绑定群首次切换到服务器**：先在云端后台确认机器人微信已登录，停止原实例的监听和回复并防止它们再次启动，然后由部署人员在服务器运行以下命令。接管命令按迁移记录核对账号和群身份，从当前微信事件位置开始监听。以后通常只需 systemd 自动恢复服务。

```sh
cd /opt/ergou/current
sudo -u ergou /usr/bin/python3 -m deploy.group_workers take-over
sudo systemctl enable --now ergou-listener.service ergou-replies.service
```

## Windows 启动

### 微信入群欢迎和退群提醒

进入「成员通知」，先选择群，再分别控制「新人入群欢迎」和「退群提醒」。真实微信绑定的每一项初始均关闭。后台申请后，双击 [确认成员通知.cmd](确认成员通知.cmd)，核对目标群和通知类型，确认才开始监测。关闭立即生效，重新开启要单独确认。欢迎语沿用「群配置」里的模板和群规链接，退群提醒使用成员原来的群内昵称或公开昵称。

插件优先响应微信的群资料更新事件，并周期复核完整名册。首次读取、重连、新开启某项和长时间无法取得完整名册时，先建立基线。连续两次可靠观察之间新增或消失的成员才会触发对应通知。如果有人在两次观察之间进群又退群，插件可能看不到。后台可查看最近一次完整快照的时间，通过「发送任务」核对投递回执。

双击「打开运营后台.cmd」会检查并恢复已登记的后台、微信插件和当前绑定获准的工作进程。重启电脑后也可使用这个入口。若单独使用解压包，请将固定的 Agent WeChat 2.7.1 程序放回原目录，或通过 `ergou/live_start.ps1 -NativeExe 路径` 指定它。

真实群的一次性固定文字通知可在「定时通知」中创建，随后由本机使用者双击 [确认微信通知.cmd](确认微信通知.cmd)，按编号核对群 ID、时间和正文后确认。每次确认只对该通知版本有效，停用、编辑或更换绑定会使旧授权失效。循环通知和动态天气新闻仍按各群原有接入权限执行。

点名后可使用「二狗点歌 茉莉花」获取 Apple Music 官方搜索链接，「二狗菜谱 土豆」查本地做法，「二狗百科 小熊猫」获取中文维基百科摘要与来源链接。百科仅发送查询词，每群成员的身份及上下文留在本机。

### 群管理员切换智能对话

在目标群的「大模型配置」中选择 DeepSeek、智谱 GLM、通义千问（百炼北京）或 ChatGPT（OpenAI API），填写该供应商的官方 API Key。后台会自动读取模型列表，也可以手动刷新。本群已保存同一供应商的密钥时可直接获取。选择支持文字聊天的模型，点击「测试并启用」。收到有效的测试回答后，新配置才用于本群的智能对话。仅查看列表或测试失败时，群聊继续使用原配置。选择智谱时会立即加载官方公布的文字模型，测试时才需要密钥。[DeepSeek 模型列表](https://api-docs.deepseek.com/api/list-models/) · [智谱官方模型定义](https://docs.bigmodel.cn/openapi/openapi.json) · [百炼模型列表](https://help.aliyun.com/zh/model-studio/list-models) · [OpenAI 模型列表](https://developers.openai.com/api/reference/resources/models/methods/list)

在工作台选择目标群，打开「大模型配置」。运营管理员或系统管理员可以从最近发言的成员中选择，也可以粘贴稳定的微信成员 ID，再点击「保存管理员名单」。成员必须使用微信的 @ 选择器点名本群机器人。两条命令分别是 `@二狗 开启智能对话` 和 `@二狗 关闭智能对话`。开启需要本群已有通过官方接口验证的模型。群内关闭保留密钥、取消排队的模型回复并重置会话。已向供应商发出的请求可能已经计费。点名查询、游戏、优先级关键词和本地故事接续在关闭后继续工作。

「自定义回复」支持精确、包含及指定阈值的相似匹配。按拖拽顺序取第一条命中，管理员开关始终先处理。模拟群可以预览 HTTPS 图片；仅点名文字授权的微信群收到图片链接。「群配置」支持逐游戏停用、欢迎模板及群规网址。定时通知支持文字活动、实时天气、香港政府新闻网要闻及天气与要闻组合。「群组运营」提供群的工作台昵称、解绑、近七天统计、今日热门关键词、错误记录及积分兑换核销。

### 微信群语音唤醒

在运营后台选中目标群，打开「语音唤醒」，填写具备短语音识别和同步语音合成权限的百度 API Key 或 Access Token。已有本群凭据或服务环境凭据时，可选择「复测当前凭据」。默认使用内置普通话录音“二狗，二狗，语音测试”，也可选择自己的 16 kHz、16 位、单声道 PCM WAV（最长 60 秒）。点击「测试并启用」，页面会显示百度识别的原文，并提供二狗合成的测试回复供试听。测试在后台完成，群成员不会收到测试消息。

识别出双唤醒词及其后的指令，且百度成功合成回复后，点击「确认启用本群凭据」即可启用这套凭据。测试结果有效期为 10 分钟。更换密钥时，原有已验证凭据会工作到新凭据确认启用，测试失败可以直接重试。本群凭据由 Windows 当前用户加密保存。服务环境中的 `ERGOU_BAIDU_SPEECH_KEY` 或 `ERGOU_BAIDU_SPEECH_TOKEN` 同样需要逐群测试，换值后要重新验证。

首次开群语音时，点击「申请开启语音唤醒」，并在本机打开 [确认语音唤醒.cmd](确认语音唤醒.cmd) 核对目标群。已有本机授权的群在确认启用凭据后即可接收新语音。后台可随时关闭本群语音。

开关生效后，插件将本群其他成员新发的短语音（最长 60 秒）提交百度识别。普通群聊语音也需要识别才能判断唤醒词。识别文字以“二狗二狗”开头才执行指令，例如“二狗，二狗，积分”。二狗把查询、游戏或聊天的回答合成为一条微信语音发回原群。较长回答朗读前 120 字并提示截短。无凭据、关闭或未确认时不下载录音。识别与合成使用百度账号的配额。[百度短语音识别](https://ai.baidu.com/ai-doc/SPEECH/Jlbxdezuf) · [百度同步合成](https://ai.baidu.com/ai-doc/SPEECH/xmw03avls)

模拟群可以在「运行概览」上传自选的 16 kHz 单声道 WAV，测试相同唤醒词并试听合成回复。

本机已部署的微信实例使用 [打开运营后台.cmd](打开运营后台.cmd) 进入 8766 端口的工作台。首次打开时为绑定群的运营账号 `operator` 设置密码。选择群，进入「大模型配置」，选择官方供应商和模型 ID，输入 API Key，点击「测试并启用」。测试发出一条固定问候，可能产生供应商费用。更换模型或密钥时，验证通过后生效；点击「停用并移除密钥」可关闭本群模型。密钥由运行后台的 Windows 用户加密保存，恢复备份后需要重新配置。每位成员在每个群有独立的最近 16 轮模型对话，上下文保存在运行内存中，静默 30 分钟或重启后重新开始。

本地模拟实例可双击 [启动二狗.cmd](启动二狗.cmd)，或在项目目录运行下方命令。首次启动会创建本地数据，并请你设置后台账号 `admin` 的密码（至少 12 个字符，输入时不回显）。看到监听地址后打开浏览器登录。

```powershell
.\start.ps1
```

后台地址为 `http://127.0.0.1:8765`。可用 `-Port 端口号` 改端口。运行概览中选择 `demo-group`，在“模拟群消息”依次输入以下命令即可打通开局、完成和积分查询。

```text
二狗 开始 成语接龙
二狗 G01 意气风发
二狗 G01 发扬光大
二狗 G01 大功告成
二狗 积分
```

示例的 G01 是新群首局编号。已有记录时使用实际返回的编号。在 PowerShell 禁止执行脚本的环境，可使用标准 Python 命令启动。

```powershell
python -m ergou init --demo
python -m ergou user admin
python -m ergou serve
```

Python 版本锁定与组件来源见 [环境矩阵](COMPONENTS.md)。本机核心无需安装第三方 Python 包。工作目录的 `data/` 存放数据库和备份，已在 Git 排除规则中。关闭服务可在启动窗口按 Ctrl+C。

## 群指令

在微信群发 **「二狗菜单」**，或用微信的 @ 选择器点名机器人后发「菜单」，即可收到一条按本群开关和本人权限整理的功能说明。菜单展示智能对话的当前状态，附有聊天、生活查询、娱乐、积分、游戏和群互动的用法。已开启智能对话时，试着发「二狗，帮我想三个周末活动」，再发「二狗，换成室内的」。菜单和积分等内置指令可以直接使用，无需大模型密钥。

独立扫码微信接入的文字前缀为“二狗”，可直接连写或加空格。模拟群使用本群配置的前缀。登记的机器人和自身消息会忽略。命令错误包括参数不合法、会话不存在、权限不足、功能关闭、供应商不可用、已截止和频率限制。相同来源消息 ID 重投会复用已入库事件。

|命令（省略前缀）|参数与权限|
|---|---|
|菜单、功能菜单、全部功能、帮助|普通成员；菜单按本群功能和发起人的权限展示。「帮助」仍可由本群自定义回复覆盖|
|游戏列表、群规|分别查看本群可开的游戏、已设置的群规|
|开始 游戏名|普通成员；本群开放游戏生效。同款同时一局，每群最多三局|
|加入 G01、退出 G01|普通成员；发起人使用结束指令离开|
|G01 动作|已报名成员；可行动作取决于当前游戏。发起人或群管理员可输入 `G01 重置` 回到开局局面，截止时间沿用原局|
|状态 G01、结束 G01|状态供成员查看。结束限发起人或群管理员，取消局无积分|
|积分、总榜、周榜、月榜|本群稳定成员 ID 隔离，周一/每月一日北京时间零时起算，同分并列|
|运势|成员每日固定娱乐签|
|天气 [城市]|省略时取群默认城市；显示数据时间、来源，10 分钟缓存|
|快递 圆通 单号|支持快递鸟 1002 所列承运商，另支持 DHL。查询仅返回承运商与状态|
|投票 创建 [多选 ]主题\|选项一\|选项二|群管理员；2–9 个不同选项，10 分钟截止|
|投票 V01 [1,2]|成员；截止前可改票，省略选项查看人数及各项票数|
|抽签 报名、抽签 退出|成员维护本群主动报名池|
|抽签 开始 [人数]、抽签 重抽 人数 原因|群管理员；默认一人，候选快照、结果及操作者持久保存|

通过 `python -m ergou say "二狗 帮助"` 也可验证模拟链路。模拟群的 `operator` 是群管理员。真实成员授权按平台稳定 ID 配置，后台登录名与微信昵称独立。游戏逐项规则见 [游戏目录](GAMES.md)。

## 后台操作

运行概览显示当前后台用户获授的群总数、其中可提供服务的群数，以及选中群的消息指标。运行告警按分钟检查账号离线、群绑定暂停、发送结果未知和入站积压。重复采样保留首次发现时间，条件解除后显示恢复时间。

在「运行概览」的「本群回复诊断」点击「刷新诊断」，可核对所选群的插件心跳、点名授权，以及最近十条已登记的点名文字或群语音处理结果。「微信已受理」表示插件取得微信回执，「微信发件已核对」表示还查到了该群的对应发件记录。诊断也会显示未唤醒的语音和等待人工核对的投递。

运行概览显示入站与投递状态。群配置可修改命令前缀、开关、局数、积分、群规、欢迎语、关键词及动作。保存使用版本号，并发冲突需刷新。设置只影响新局的奖励规则。欢迎语预览展示成员、群、时间和群规的替换效果。定时通知按北京时间创建，可选择错过十分钟内补发。发送结果未知时，管理员可核对后结束跟进或标记经人工确认的结果。

会话、积分流水、规则命中、周报、入站异常、发送任务、权限和审计均受后端群授权约束。各页的 CSV 导出使用相同权限，写入文本前缀以处理公式字符。积分调整与冲正须填写原因。已启用群级告知留存时，系统管理员可在撤回记录页按事件号反查。缓存上限 2,048 条或 2 MiB，最多 24 小时，服务重启即清空。

创建其他后台用户（从控制台输入密码）：

```powershell
python -m ergou user reviewer --role 只读人员 --group demo-group
```

## 接入及外部服务

本机已用 Agent WeChat 2.7.1 建立独立扫码会话，通过 SSE 订阅绑定群的新消息。文字监听组件为 `agent-wechat-events/2.7.1`，启用群语音后由 `agent-wechat-voice/2.7.1` 处理语音指令。实机数据库和演示库分开运行。查看状态与重启步骤见 [独立扫码会话](ergou/wechaty/README.md#agent-wechat-独立扫码会话)。

监听个人微信群消息的插件采用 Wechaty 的 `message` 回调。后台选择授权群后，“群消息接收记录”可查看来源消息 ID、成员 ID 和处理状态。接入步骤、GitHub 选型依据、本机微信版本的限制及验收方法见 [微信群消息监听](ergou/wechaty/README.md)。

已有 WeFlow 本地 API 的用户可以用 Python 直接读取指定群的增量文本。运行 `python -m ergou.weflow health` 检查本机接口。群身份核对、启停命令和恢复范围见 [WeFlow 单群接入](ergou/wechaty/README.md#weflow-单群接入)。

接入节点通过独立账号密钥与本机服务对接，见 [接口与插件](API.md)。开源天气接口 Open-Meteo 的托管免费服务限非商业用途，需署名。部署的天气查询上限 500 次/北京时间自然日，每次未缓存查询最多包含地名和天气两个请求。供应商还可独立限流。[Open-Meteo 使用条款](https://open-meteo.com/en/terms)

国内快递已接入快递鸟 1002，使用 `ERGOU_KDN_ID`、`ERGOU_KDN_KEY` 环境变量。免费方案需注册并具备对应权益，承运商范围受账号套餐影响。DHL 使用 `ERGOU_DHL_KEY`。本地快递查询预算合计 200 次/日。密钥在本机服务启动环境中配置，界面只显示配置状态。快递功能缺凭据时会明确提示。[快递鸟接入说明](https://www.kdniao.com/message/detail/116105) · [DHL Tracking](https://developer.dhl.com/api-reference/shipment-tracking)

## 部署、恢复与验收

1. 在同一 Windows 主机的本地磁盘安装 64 位 Python 3.12；使用固定服务身份运行，限制数据库和备份目录的访问权。用 `python -m ergou --db 路径 init` 初始化。远程管理部署需要另配 TLS、入口访问控制，服务默认只监听回环地址。
2. 先启动业务服务，再启动已验证的桌面接入节点。节点应在有微信图形会话的用户桌面运行。停止服务前停止接入节点并检查发送队列。后台可以从发送任务和入站异常页查看状态。
3. 运行服务每天北京时间 03:30 后执行当日的 SQLite 在线备份并保留最近七份。升级前也可运行 `python -m ergou backup 备份.sqlite`。命令输出 SHA-256。备份包含配置、授权哈希、未完成任务和业务历史，须限制文件权限。
4. 恢复到一个新的隔离文件：`python -m ergou --db 恢复.sqlite restore 备份.sqlite`。恢复检查数据库版本与完整性、清理登录会话，暂停全部绑定，未决发送进入 UNKNOWN。核对账号、群、过期及未知任务后，通过身份已验证的节点和管理员切换流程开放服务。
5. 升级时保留旧版程序和已校验的备份，在独立数据目录启动并执行回归。若不兼容，停止新版，在旧版配套数据副本上恢复；切换后的业务需单独核对。进程崩溃恢复和灾难备份恢复采用不同流程。
6. 运行 `python -m unittest discover -v` 做本地验证。短时模拟压测为 `python -m tests.benchmark --events 1000`，默认 200 群、每群三局、三种命令占比、分散与热点各一组。真实平台和长稳项目见验收记录。
