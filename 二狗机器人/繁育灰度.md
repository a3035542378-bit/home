# 鱼塘繁育首周灰度

功能开关使用 SQLite 中的稳定微信群 ID。迁移默认不启用任何群。本次只启用「我们的小小家」，同名群及以后新绑定的群均需另行授权。

## 微信用法

| 玩家想做什么 | 发送 |
|---|---|
| 找可配对的同种成年亲鱼 | 二狗繁育配对 |
| 查看两条实物、重量、成功率和费用 | 二狗繁育配对#17 #21 |
| 确认该报价并扣款 | 二狗确认配对#17 #21 |
| 查看出结果的北京时间 | 二狗繁育状态 |
| 看塘并查看首屏待领提醒 | 二狗鱼塘 |
| 领取一尾，查看品种与来源 | 二狗领取幼鱼 |

编号取自本人的本群鱼塘，报价 10 分钟有效。两条亲鱼需一直同塘到出结果，每人每群一次一对。定型的野生鱼及长到成年的繁育鱼均可当亲鱼。每次 6 鱼币，75% 成功，30 分钟出结果；失败或亲鱼提前离塘不退费。领苗需要空塘位，满塘时保留待领。幼鱼在成长位自然长大，出售值 2 币，成年值 3 币。首尾以首次实际领取为准，来源随鱼号保留。

## 开关与回滚

在 Linux 发布目录运行，仅在已核对的绑定群执行。首次启用记录精确起点，重复启用和服务重启沿用同一统计窗口。

```sh
runuser -u ergou -- python3 -m tools.breed_pilot enable /var/lib/ergou/ergou.sqlite STABLE_GROUP_ID
runuser -u ergou -- python3 -m tools.breed_pilot week /var/lib/ergou/ergou.sqlite STABLE_GROUP_ID
runuser -u ergou -- python3 -m tools.breed_pilot disable /var/lib/ergou/ergou.sqlite STABLE_GROUP_ID
```

优先按群关闭入口：关闭后报价作废，配对、权益、鱼号、钱包、统计及育苗计价仍保留，再次启用可继续领取。在首次开放前若发布失败，可切回上一发布目录。开放产生真实育苗资产后应保留认识育苗的代码版本，使用群开关止损；直接回退到旧估价代码可能按野生鱼规则处理幼鱼。生产库备份用于灾备，回滚群开关无需还原数据库。

## 首周报表口径

自首次启用时刻起连续 168 小时，右端时刻不计入。进行中可查看累计数，满七天后同一条命令读取首周结果。统计仅输出本群汇总，无需拉取聊天正文。

- **有资格配对**：窗口内曾同时拥有两条同种成年塘鱼的去重玩家数，按亲鱼条件统计，余额另在确认时校验。保留最早资格到达时间，使用原成长算法计算尚在成长位的到期点；换位、投喂、升级、出售、转手、换展后更新。没有任何进一步查看的离线玩家也可计入。
- **首次发起配对**：确认并实际扣费的玩家数，查看报价不计。
- **成功后领取**：实际领过至少一尾的玩家数，到期尚待领不计。
- **留下首尾幼鱼**：在报表截止时，领取的第一尾仍归原繁育人所有，包括鱼塘、鱼包和图鉴，按鱼号追踪已售和转手。第二周的变化不会倒改首周数。
- **发起第二次配对**：已确认至少两次配对的人数，包含首次失败后的重试。另列「首领后再次配对」，用于区分重试和收藏后的复玩。
- **实际鱼币净回收**：窗口内实收配对费减所有繁育来源鱼在本群的实际出售到账，含整包、整塘与转手后出售。不包含估值、未领资格、饲料、扩塘和修竿费用。
